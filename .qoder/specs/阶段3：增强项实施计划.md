## #40 四项改进

### 改进1：遗留字段补全

- **模型**：`backend/app/models/investor_holding.py` 加 3 列 `market_value`/`total_cost`/`profit`（`Numeric(15,4)`，nullable）。
- **迁移**：新建 `backend/alembic/versions/0002_investor_holding_derived_fields.py`，revision=`0002`，down_revision=`0001`。用 `try/except op.add_column` 包裹每列（幂等，兼容 create_all 全新部署），downgrade 删 3 列。
- **回填 market_value/total_cost/profit**：`backend/app/services/snapshot_service.py` `_generate_investor_holding`（L846-853 InvestorHolding 构造处）加：
  ```python
  market_value = prev_shares * Decimal(str(value_snapshot.unit_price))
  total_cost = prev_shares * prev_cost
  profit = market_value - total_cost
  ```
  注入 InvestorHolding(...) 构造参数。`value_snapshot` 已是函数入参（L761），无需新查。
- **回填 unit_price_change_pct**：`_generate_portfolio_value_snapshot`（L745-752 PortfolioValueSnapshot 构造处）。复用已查到的 `prev_pvs`（L708-712）：
  ```python
  if prev_pvs and prev_pvs.unit_price and prev_pvs.unit_price > 0:
      unit_price_change_pct = (unit_price - Decimal(str(prev_pvs.unit_price))) / Decimal(str(prev_pvs.unit_price))
  else:
      unit_price_change_pct = Decimal("0")
  ```
  注入 PortfolioValueSnapshot(...) 构造参数。
- **回填 frozen_amount**：`_generate_portfolio_position`（L667 当前 `frozen_amount=0`）。新增 helper `_calculate_frozen_amount(db, portfolio_code, platform_code, target_date)`：查 pending CASH sells（`Trade.product_code=="CASH" AND status=="pending" AND trade_type=="sell" AND platform_code==X`）SUM(amount)。注意：仅 CASH 持仓行计算，非 CASH 行 frozen_amount 保持 0（份额冻结用 frozen_shares）。

### 改进2：SQLAlchemy event listener 兜底

- `backend/app/models/portfolio_position.py` 末尾加 mapper-level listener：
  ```python
  from sqlalchemy import event

  @event.listens_for(PortfolioPosition, "before_update")
  def _prevent_position_update(mapper, connection, target):
      raise RuntimeError("portfolio_position 快照不可更新，请使用 recalculate_snapshots")

  @event.listens_for(PortfolioPosition, "before_delete")
  def _prevent_position_delete(mapper, connection, target):
      raise RuntimeError("portfolio_position 快照不可直接删除，请使用 DELETE /snapshots/{portfolio}/{date}")
  ```
- **绕过**：`_delete_existing_snapshots`（L408-411）当前 `db.query(PortfolioPosition).filter(...).delete()` 是 ORM bulk delete，不触发 instance-level mapper event。但为语义清晰 + 防御未来单行 `db.delete(obj)`，改用 `db.execute(delete(PortfolioPosition).where(...))`，加注释说明 listener 绕过意图。需 `from sqlalchemy import delete`。
- **注册时机**：listener 在 `portfolio_position.py` import 时注册，conftest 已 import models，测试环境自动生效。

### 改进3：平台覆盖检查改为默认阻断 + force_cover 降级

> **冲突标注**：spec §3.4 与 AGENTS.md 写"warning（不阻断）"，issue #40 改进3 要求"默认阻断 + force_cover 降为 warning"。用户指示按 issue 原文实施，本计划采用 issue 方案，推翻 spec §3.4 的"不阻断"。
