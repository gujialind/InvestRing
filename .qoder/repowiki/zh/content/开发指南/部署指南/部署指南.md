## 项目概述

InvestRing 是一个现代化的投资组合管理平台，采用前后端分离架构。后端基于 Python FastAPI 框架，前端使用 Next.js 构建，支持 Docker 容器化部署和 Kubernetes 编排。

### 技术栈
- **后端**: Python 3.11+, FastAPI, SQLAlchemy, Alembic
- **前端**: Next.js 14, React, TypeScript
- **数据库**: PostgreSQL 15+
- **缓存**: Redis 7+
- **消息队列**: Celery + Redis
- **容器化**: Docker, Docker Compose
- **编排**: Kubernetes
- **CI/CD**: GitHub Actions

## 环境要求

### 硬件要求
- **最小配置**: 2核 CPU, 4GB RAM, 50GB 存储
- **推荐配置**: 4核 CPU, 8GB RAM, 100GB SSD 存储
- **高可用部署**: 至少 3 个节点，每个节点满足推荐配置

### 软件要求
- **操作系统**: Ubuntu 20.04+, CentOS 8+, 或任何支持 Docker 的现代 Linux 发行版
- **Docker**: 20.10+
- **Docker Compose**: 2.0+
- **Kubernetes**: 1.24+ (可选)
- **PostgreSQL**: 15+
- **Redis**: 7+

### Nginx 反向代理配置

Nginx 配置文件位于 `nginx/nginx.conf`，主要功能包括：

- SSL/TLS 终止
- 静态资源缓存
- 请求路由和负载均衡
- 安全头设置
- 访问日志和错误日志

#### SSL 证书配置

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取 SSL 证书
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# 自动续期
sudo systemctl enable certbot.timer
```

#### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    
    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;
    
    # SSL 配置
    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    
    # 安全头
    add_header X-Frame-Options DENY;
    add_header X-Content-Type-Options nosniff;
    add_header X-XSS-Protection "1; mode=block";
    
    # 前端静态资源
    location / {
        proxy_pass http://frontend:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }
    
    # 后端 API
    location /api/ {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
    
    # 健康检查
    location /health {
        access_log off;
        return 200 '{"status": "healthy"}';
        add_header Content-Type application/json;
    }
}
```

## Docker 容器化部署

### Docker 镜像构建

项目包含优化的 Dockerfile，支持多阶段构建以减小镜像大小：

#### 后端镜像构建

```dockerfile
# 多阶段构建
FROM python:3.11-slim AS builder

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /install /usr/local
COPY . .
EXPOSE 8000
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

#### 前端镜像构建

```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/out /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### Docker Compose 部署

#### 生产环境配置

`docker-compose.yml` 定义了完整的生产环境：

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_DB: investring
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${DB_USER} -d ${DB_DB}"]
      interval: 10s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    command: redis-server --requirepass ${REDIS_PASSWORD}
    volumes:
      - redis_data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    environment:
      DATABASE_URL: postgresql://${DB_USER}:${DB_PASSWORD}@postgres:5432/${DB_NAME}
      REDIS_URL: redis://:${REDIS_PASSWORD}@redis:6379/0
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    restart: unless-stopped
    deploy:
      resources:
        limits:
          cpus: '1.0'
          memory: 512M
        reservations:
          cpus: '0.5'
          memory: 256M

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    ports:
      - "3000:80"
    depends_on:
      - backend
    restart: unless-stopped

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf
      - ./certs:/etc/nginx/certs
    depends_on:
      - frontend
      - backend
    restart: unless-stopped

volumes:
  postgres_data:
  redis_data:
```

### 备份策略

#### 自动备份脚本

```bash
#!/bin/bash
# backup.sh

BACKUP_DIR="/backups/investring"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=30

# 创建备份目录
mkdir -p $BACKUP_DIR

# 执行数据库备份
docker exec investring-postgres-1 pg_dump -U postgres investring > $BACKUP_DIR/db_$DATE.sql

# 压缩备份
gzip $BACKUP_DIR/db_$DATE.sql

# 清理旧备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +$RETENTION_DAYS -delete

# 上传到云存储
aws s3 cp $BACKUP_DIR/ s3://investring-backups/ --recursive

# 发送通知
echo "Backup completed: db_$DATE.sql.gz" | mail -s "InvestRing Backup" admin@example.com
```

#### 增强版回滚机制

**已更新** 部署工作流现在包含增强的迁移间隙检测和预回滚验证逻辑：

```bash
# 自动迁移间隙检测
docker exec investring-backend-1 alembic current
docker exec investring-backend-1 alembic history

# 预回滚验证（在健康检查失败时自动触发）
docker exec investring-backend-1 alembic downgrade -1 --dry-run

# 自动回滚流程
if [ $? -ne 0 ]; then
    echo "Migration failed, initiating rollback..."
    docker exec investring-backend-1 alembic downgrade -1
    docker-compose up -d backend:v1.2.3
fi
```

### GitHub Actions 部署工作流增强

**已更新** 部署工作流现在包含智能迁移间隙检测：

```yaml
# .github/workflows/deploy.yml 中的增强部分
- name: Database Migration Check
  run: |
    # 检查当前数据库版本
    CURRENT_VERSION=$(docker exec investring-backend alembic current)
    echo "Current DB version: $CURRENT_VERSION"
    
    # 检查是否有未应用的迁移
    UPGRADE_CHECK=$(docker exec investring-backend alembic upgrade head --dry-run)
    if [ $? -ne 0 ]; then
      echo "Migration check failed, triggering pre-rollback validation"
      # 执行预回滚验证
      docker exec investring-backend alembic downgrade -1 --dry-run
      if [ $? -eq 0 ]; then
        echo "Pre-rollback validation successful"
      else
        echo "Pre-rollback validation failed, aborting deployment"
        exit 1
      fi
    fi

- name: Health Check with Auto-Rollback
  run: |
    # 健康检查循环
    for i in {1..10}; do
      HEALTH_STATUS=$(curl -s http://backend:8000/health)
      if [ "$HEALTH_STATUS" == '{"status": "healthy"}' ]; then
        echo "Service is healthy"
        break
      fi
      
      # 健康检查失败时自动触发回滚
      if [ $i -eq 10 ]; then
        echo "Health check failed, initiating automatic rollback"
        docker-compose up -d backend:v${PREVIOUS_VERSION}
        exit 1
      fi
      
      sleep 30
    done
```

#### Redis 缓存策略

```python
# app/services/cache_service.py
import redis
import json
from functools import wraps

class CacheService:
    def __init__(self):
        self.redis = redis.Redis(host='redis', port=6379, db=0)
    
    def cache(self, key, ttl=300):
        def decorator(func):
            @wraps(func)
            def wrapper(*args, **kwargs):
                cache_key = f"{func.__name__}:{hash(str(args))}"
                
                # 尝试从缓存获取
                cached = self.redis.get(cache_key)
                if cached:
                    return json.loads(cached)
                
                # 执行函数并缓存结果
                result = func(*args, **kwargs)
                self.redis.setex(cache_key, ttl, json.dumps(result))
                
                return result
            return wrapper
        return decorator
    
    def invalidate(self, pattern):
        """清除匹配的缓存"""
        keys = self.redis.keys(pattern)
        if keys:
            self.redis.delete(*keys)
```

from datetime import datetime, timedelta
from jose import jwt
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def verify_password(plain_password, hashed_password):
    return pwd_context.verify(plain_password, hashed_password)

def get_password_hash(password):
    return pwd_context.hash(password)

def create_access_token(data: dict, expires_delta: timedelta = None):
    to_encode = data.copy()
    expire = datetime.utcnow() + (expires_delta or timedelta(minutes=15))
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

def validate_token(token: str):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return payload
    except jwt.JWTError:
        return None
