# InvestRing 投资年轮 - 开发总览

---

## 1. 项目概述

InvestRing（投资年轮）是一个面向大家庭的家庭投资组合管理系统。

**核心特性**：
- 净值化管理：每个组合以净值方式管理，支持多投资人份额分账
- 用户认证：admin/viewer 角色权限，HMAC Token 认证
- 两端独立：移动端/PC端独立页面，最优体验

---

## 2. 技术架构

```
前端 (Next.js 14+ App Router)
├── shadcn/ui + TailwindCSS v4
├── 两套独立路径：/m/（移动端）+ 根路径（PC端）
└── PWA离线能力 (serwist)
        │ REST API
        ▼
后端 (FastAPI)
├── SQLAlchemy + MySQL 8.x
├── HMAC Token 认证
└── 75个API接口
        │
        ▼
外部数据源
└── Tushare API / Akshare API
```

**技术选型**：

| 层级 | 技术 |
|------|------|
| 前端框架 | Next.js 14+ (App Router) |
| UI组件 | shadcn/ui + TailwindCSS v4 |
| 状态管理 | Zustand + React Query |
| 后端框架 | FastAPI |
| ORM | SQLAlchemy 2.x |
| 数据库 | MySQL 8.x |
| 认证 | HMAC Token（7天有效期） |

**数据库配置**：
- 使用环境变量配置数据库连接
- 支持连接池配置
- 字符集：utf8mb4

## 7. 开发注意事项

- **AI全权开发**：所有代码由AI生成
- **移动端优先**：数据层共享，页面独立实现
- **PC端高频使用**：admin每天操作，需优化体验
- **所有用户必须设置密码**：无免密登录
- **所有资产人民币计价**：无汇率换算
- **快照与实时计算分离**：快照记录历史状态，所有可用资金/份额必须实时计算（详见 03-业务流程设计.md "可用资金计算规则"）
