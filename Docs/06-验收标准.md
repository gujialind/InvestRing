# InvestRing 验收标准

> 用途：基于最新数据库设计（21张表）和业务流程设计
> 版本：v1.32（2026-04-24更新）

## 1. 功能验收清单

### 1.1 用户认证

| 验收项 | 验收标准 | 测试方法 |
|--------|----------|---------|
| 登录成功 | 正确的编码+密码返回token，跳转首页 | 手动登录 |
| 登录失败 | 密码错误返回401，显示错误提示 | 输入错误密码 |
| 账户锁定 | 连续失败5次锁定15分钟 | 连续输错5次 |
| Token过期 | 7天后token过期，自动跳转登录页 | 等待或手动修改时间 |
| Token清除 | 清除浏览器Token实现"登出" | 清除浏览器数据 |
| 修改密码（自己） | 验证原密码，更新成功后token失效 | viewer修改自己密码 |
| 修改密码（他人） | admin无需原密码可修改任意用户密码 | admin修改他人密码 |

### 1.2 权限控制

| 验收项 | 验收标准 | 测试方法 |
|--------|----------|---------|
| admin全权 | 可访问所有页面、执行所有操作 | admin账户测试各功能 |
| viewer只读 | 可查看但不能创建/修改/删除 | viewer账户尝试各操作 |
| 接口权限 | viewer调用管理接口返回403 | 用viewer token调用POST接口 |
| 前端隐藏 | viewer看不到管理入口（按钮、菜单） | viewer账户查看界面 |

### 1.3 投资人管理

| 验收项 | 验收标准 | 测试方法 |
|--------|----------|---------|
| 创建投资人 | 必须设置密码，bcrypt哈希存储 | 创建后检查数据库 |
| 移除投资人 | 有份额时拒绝，无份额时创建移除快照（shares=0） | 尝试移除有/无份额的投资人 |

### 1.4 组合管理

### 1.5 申购赎回

| 验收项 | 验收标准 | 测试方法 |
|--------|----------|---------|
| 申购提交 | 输入金额（元），创建pending记录，不影响份额 | 提交后检查数据库 |
| 申购确认 | 份额增加，净值不变 | 确认后检查份额和净值 |
| 赎回提交 | 输入份额（份），冻结份额，创建pending记录，显示预估金额 | 提交后检查冻结份额和预估金额 |
| 赎回确认 | 份额减少，现金减少，净值不变 | 确认后检查数据 |
| 赎回取消 | 解冻份额，记录作废 | 取消后检查数据 |
| 可用份额校验 | 赎回份额超过可用份额时拒绝 | 尝试超额赎回 |

### 1.6 调仓交易

| 验收项 | 验收标准 | 测试方法 |
|--------|----------|---------|
| 买入提交 | 冻结现金，创建pending记录 | 提交后检查冻结金额 |
| 买入确认 | 扣现金、解冻、生成持仓 | 确认后检查数据 |
| 卖出提交 | 冻结持仓份额 | 提交后检查冻结份额 |
| 卖出确认 | 扣持仓、解冻、增加现金 | 确认后检查数据 |
| 可用现金校验 | 买入金额超过可用现金时拒绝 | 尝试超额买入 |
| 现金中转约束 | 买入只能使用已有可用现金，卖出pending不增加可用现金 | 提交卖出+买入，买入金额>已有现金但<已有现金+卖出金额 |
| 批量调仓 | 一次性提交多笔交易，原子性处理 | 提交批量调仓 |
| 幂等性保证 | 相同Idempotency-Key的请求只执行一次 | 使用相同Key重复提交 |

### 1.9 实时计算验收

> ⚠️ **核心原则**：所有可用资金/份额必须实时计算，不能仅读取快照。快照记录历史状态，实时计算反映当前可用。

| 验收项 | 验收标准 | 测试方法 |
|--------|----------|---------|
| 组合可用现金 | 返回值包含快照现金、pending/confirmed交易明细、实时计算结果 | 调用 GET /available-cash API |
| 可用现金正确性 | pending买入后可用现金立即减少 | 提交买入后立即查询可用现金 |
| 可用现金正确性 | confirmed买入（快照未生成）后可用现金正确减少 | T日确认买入，T日白天查询 |
| 可用现金正确性 | confirmed卖出（快照未生成）后可用现金正确增加 | T日确认卖出，T日白天查询 |
| 基金可用份额 | 返回值 = 快照份额 - pending卖出 - confirmed卖出（快照未生成） | 提交卖出后查询可用份额 |
| 投资人可用份额 | 返回值 = 快照份额 - pending赎回 - confirmed赎回（快照未生成） | 提交赎回后查询可用份额 |
| 赎回校验 | 赎回份额超过可用份额时拒绝，提示"可用份额不足" | 尝试超额赎回 |
| 买入校验 | 买入金额超过可用现金时拒绝，提示"可用现金不足" | 尝试超额买入 |
| 卖出校验 | 卖出份额超过可用份额时拒绝，提示"可用份额不足" | 尝试超额卖出 |
| 移除投资人校验 | 投资人可用份额 > 0 时拒绝移除 | 尝试移除有份额的投资人 |
| 关闭组合校验 | 存在pending交易时拒绝关闭 | 尝试关闭有待处理的组合 |

## 2. 数据验收

### 2.1 市值计算验证

```
初始条件：组合持有 1000份基金A(净值1.5元) + 2000份基金B(净值2.0元) + 现金5000元
预期：组合总市值 = 1000×1.5 + 2000×2.0 + 5000 = 10500元
```

### 2.2 净值计算验证

```
初始条件：组合净值1.2元，总市值12万，总份额10万份；投资人申购2万元
预期：
- 新份额 = 20000 / 1.2 = 16666.67份
- 总份额 = 116666.67份
- 净值 = 140000 / 116666.67 = 1.2元（不变）
```

### 2.3 QDII净值验证

```
初始条件：QDII基金持有1000份，T-2日净值2.5元（人民币计价）
预期：人民币市值 = 1000 × 2.5 = 2500元
注：所有资产均为人民币计价，无需汇率换算
```

### 2.4 冻结金额验证

```
初始条件：现金持仓10000元，冻结金额0元
操作：提交场外买入5000元（pending）
预期：现金持仓=10000元（不变），冻结金额=5000元，可用现金=5000元
```

### 2.5 成本价计算验证

```
初始条件：投资人持有10000份，成本价1.0元；申购5000元，当日净值1.2元
预期：
- 新份额 = 5000 / 1.2 = 4166.67份
- 新成本价 = (10000×1.0 + 4166.67×1.2) / (10000 + 4166.67) = 1.06元
```

## 5. 安全要求

| 验收项 | 要求 |
|--------|------|
| 密码存储 | bcrypt哈希，cost factor ≥ 10 |
| Token签名 | HMAC-SHA256，有效期7天 |
| 无状态认证 | Token无状态验证，无需数据库查询 |
| Token清除 | 清除浏览器Token实现"登出" |
| 参数校验 | 所有输入参数校验 |
| SQL注入防护 | 无SQL注入漏洞 |
| 敏感数据 | Tushare Token加密存储 |
| 登录限流 | 连续失败5次锁定15分钟 |
| 密码修改 | 修改密码后所有Token失效 |

## 6. 数据库验收

### 表结构验收

| 表名 | 验收项 |
|------|--------|
| investor | 包含password_hash、last_login_at字段 |
| portfolio | 包含status、started_at、closed_at字段 |
| portfolio_position | 快照表结构正确 |
| portfolio_value_snapshot | 包含unit_price、total_value、total_shares |
| investor_holding | 包含shares、frozen_shares、cost_per_share |
| share_change_event | 包含entitlement_date（NOT NULL） |
| idempotency_cache | 幂等性缓存表，包含key、response、expires_at |

### 数据完整性

| 验收项 | 要求 |
|--------|------|
| 外键约束 | 所有外键关系正确，组合/投资人使用RESTRICT |
| 唯一约束 | 组合+日期唯一、投资人+组合+日期唯一 |
| 非空约束 | 必填字段不允许NULL |
| 表数量 | 21张表（核心业务13张 + 日志系统7张 + 幂等性缓存1张） |
