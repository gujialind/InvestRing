# InvestRing 前端开发文档

> 用途：定义前端技术架构、页面设计和组件规范。
> 核心内容：Next.js + shadcn/ui + TailwindCSS，13个核心页面，移动端/PC端双端独立路由。

---

## 1. 技术架构

### 1.1 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | Next.js 15 (App Router) + React 19 | 文件系统路由、Server Components |
| 语言 | TypeScript 5.6 | 全量类型检查（`tsc --noEmit` 通过）|
| UI 组件库 | shadcn/ui (Radix UI) | 基于 TailwindCSS 的无样式组件 |
| 样式方案 | TailwindCSS v4 (CSS-first 配置) | `globals.css` 中 `@theme`/`@custom-variant`，无 `tailwind.config.ts` |
| 客户端状态 | Zustand v5 | 轻量，`persist` 中间件持久化 |
| 服务端状态 | @tanstack/react-query v5 | 自动缓存、`staleTime` 控制 |
| HTTP | axios | 拦截器统一附加 Token + 401 跳转 |
| 图表 | Recharts | 收益曲线、净值走势、资产配置饼图 |
| 通知 | sonner | Toast 通知（`uiStore` 统一调度）|
| 日期 | date-fns + react-day-picker | 日期选择器 |
| 图标 | lucide-react | 统一图标集 |
| 代码质量 | ESLint v9 (flat config) + next 类型 | `eslint.config.mjs`，构建期间强制 lint |

### 1.3 路由策略：双端独立路由（显式子路径）

**设计决策**：移动端使用 `/m/` 前缀，PC端使用根路径，两套独立页面。

**URL 映射表**：

| 功能 | PC端 URL | 移动端 URL |
|------|----------|-----------|
| 登录 | `/login` | `/m/login` |
| 仪表盘 | `/dashboard` | `/m/dashboard` |
| 投资人管理 | `/investors` | `/m/investors` |
| 组合列表 | `/portfolios` | `/m/portfolios` |
| 组合详情 | `/portfolio/PORT001` | `/m/portfolio/PORT001` |
| 持仓管理 | `/portfolio/PORT001/positions` | `/m/portfolio/PORT001/positions` |
| 申购赎回 | `/portfolio/PORT001/subscriptions` | `/m/portfolio/PORT001/subscriptions` |
| 调仓交易 | `/portfolio/PORT001/trades` | `/m/portfolio/PORT001/trades` |
| 产品管理 | `/products` | `/m/products` |
| 平台管理 | `/platforms` | `/m/platforms` |
| 系统设置 | `/settings` | `/m/settings` |
| 日志管理 | `/settings/logs` | `/m/settings/logs` |
| 任务管理 | `/settings/tasks` | `/m/settings/tasks` |

**原因**：
- InvestRing 是数据密集型应用，PC 端天然适合多列并排，移动端必须垂直堆叠
- 调仓交易、多组合对比等场景，PC 和移动端最优交互方案差异大
- 两套独立页面，改动隔离，各自独立演化
- 显式子路径确保 URL 明确，便于分享和 SEO

### 1.4 路由匹配策略（Middleware）

```typescript
// middleware.ts
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'

export function middleware(request: NextRequest) {
  const userAgent = request.headers.get('user-agent') || '';
  const isMobile = /Mobile|Android|iPhone|iPad|iPod/i.test(userAgent);
  const pathname = request.nextUrl.pathname;
  const token = request.cookies.get('token')?.value;
  
  // 静态资源、API 不处理
  if (pathname.startsWith('/_next') || pathname.startsWith('/api')) {
    return NextResponse.next();
  }
  
  // 根路径自动跳转
  if (pathname === '/') {
    const target = isMobile ? '/m/dashboard' : '/dashboard';
    return NextResponse.redirect(new URL(target, request.url));
  }
  
  // 手机访问PC路径 → 重定向到移动端
  if (isMobile && !pathname.startsWith('/m')) {
    const mobilePath = '/m' + pathname;
    return NextResponse.redirect(new URL(mobilePath, request.url));
  }
  
  // PC访问移动路径 → 重定向到PC端
  if (!isMobile && pathname.startsWith('/m')) {
    const desktopPath = pathname.slice(2) || '/';
    return NextResponse.redirect(new URL(desktopPath, request.url));
  }
  
  // 未登录且访问非登录页 → 重定向到登录页
  const isLoginPage = pathname === '/m/login' || pathname === '/login';
  if (!token && !isLoginPage) {
    const loginPath = isMobile ? '/m/login' : '/login';
    return NextResponse.redirect(new URL(loginPath, request.url));
  }
  
  return NextResponse.next();
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico).*)'],
};
```

**说明**：
- Middleware 在每个请求都会执行
- 根据 User-Agent 判断设备类型，自动重定向到对应版本
- 分享链接时，接收方会自动跳转到其设备对应的版本
- Token 存储在 Cookie 中，两端通用

### 1.5 组件复用策略

三层层级，越靠下越接近端差异化：

| 层级 | 复用方式 | 目录 | 说明 |
|------|----------|------|------|
| **基础共享层** | 完全共享 | `hooks/` + `lib/api/` + `stores/` + `types/` + `components/ui/` | 数据、状态、类型、UI 原子组件两端完全一致 |
| **共享业务组件层** | 双端共用 | `components/shared/` | 通过 `variant: "desktop" \| "mobile"` + `basePath` prop 适配两端布局与链接前缀 |
| **端独立层** | 独立实现 | `components/mobile/` vs `components/desktop/`、`components/layout/`；`app/m/` vs `app/` | 布局组件与各端页面入口（入口仅套 Layout + 渲染共享内容组件）|

**共享业务组件层细分**（`components/shared/`）：
- 基础件：`LoadingState`、`EmptyState`、`StatCard`
- 复合件：`PortfolioStatsCards`、`DashboardStatsCards`、`PortfolioActionButtons`
- 整页内容件：`PortfolioListContent`、`TradesContent`、`SubscriptionsContent`（含表单 + 表格 + 确认弹窗，双端共用业务逻辑）
- 弹窗件：`dialogs/ClosePortfolioDialog`、`dialogs/DeletePortfolioDialog`（用 AlertDialog 替代原生 confirm）

**设计要点**：页面入口（`app/m/...` 与 `app/...`）不再承载业务逻辑，仅 `<Layout><XxxContent basePath="..." variant="..." /></Layout>`，确保两端业务逻辑单一维护。

### 1.6 开发优先级

**并行开发**：移动端和 PC 端同步开发，共享数据层先行。

```
阶段 1：基础设施（共享层）
├── lib/api/（client + 各业务模块 + barrel index）
├── hooks/（useAuth/usePortfolio/useTrade/... + useDashboardStats）
├── stores/（authStore/uiStore）
├── types/（全量类型定义）
└── components/ui/（shadcn/ui）

阶段 2：共享业务组件层
├── components/shared/（基础件 + 复合件 + 整页内容件 + dialogs）

阶段 3：并行开发各端页面入口
├── 移动端 app/m/                ├── PC 端 app/
│   ├── 套 MobileLayout          │   ├── 套 MainLayout
│   └── 渲染 *Content(variant=   │   └── 渲染 *Content(variant=
│       "mobile", basePath=         │       "desktop", basePath=
│       "/m/...")                    │       "/...")
└── 图表组件（共享）
```

## 8. 认证策略

### 8.1 Token 存储与管理

```typescript
// Token 存储
localStorage.setItem('token', response.token);
localStorage.setItem('token_expires_at', response.expires_at);
localStorage.setItem('user', JSON.stringify(response.user));

// Token 获取
const token = localStorage.getItem('token');
const expiresAt = localStorage.getItem('token_expires_at');

// Token 过期检查
function isTokenExpired(): boolean {
  const expiresAt = localStorage.getItem('token_expires_at');
  return expiresAt ? Date.now() > Number(expiresAt) : true;
}
```

### 8.2 路由守卫

```typescript
// middleware.ts
export function middleware(request: NextRequest) {
  const token = request.cookies.get('token');
  const pathname = request.nextUrl.pathname;
  
  // 未登录且访问非登录页 → 跳转登录页
  if (!token && pathname !== '/login') {
    return NextResponse.redirect(new URL('/login', request.url));
  }
  
  // 已登录且访问登录页 → 跳转首页
  if (token && pathname === '/login') {
    return NextResponse.redirect(new URL('/', request.url));
  }
  
  return NextResponse.next();
}
```

### 8.3 权限控制

| 用户角色 | 可访问页面 | 可执行操作 |
|---------|-----------|-----------|
| admin | 全部页面（13个） | 全部操作 |
| viewer | 登录页、首页、组合列表/详情、持仓管理（只读）、申购赎回（只读）、调仓交易（只读） | 仅查看，无创建/修改权限 |

**实现方式**：
- 前端根据 `user.role` 隐藏管理入口（按钮、菜单项）
- admin 专属页面：投资人管理、产品管理、平台管理、设置页、日志管理页、任务管理页
- 后端 API 校验角色，viewer 调用管理接口返回 403

### 8.4 登录流程

```
1. 用户输入编码 + 密码
2. 调用 POST /api/auth/login
3. 成功：存储 token + user 信息，跳转首页
4. 失败：显示错误提示
   - 密码错误：提示"用户编码或密码错误"
   - 账户锁定：提示"账户已锁定，请15分钟后重试"
```

### 8.5 Token 过期处理

```typescript
// API 请求拦截器
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // Token 过期或无效
      localStorage.clear();
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);
```

### 8.6 登出流程

```
1. 调用 POST /api/auth/logout（将 token 加入黑名单）
2. 清除 localStorage（token、user 信息）
3. 跳转登录页
```
