# InvestRing 产品需求文档

> 版本：v1.19

---

## 1. 功能需求

### 1.1 用户规模

- 大家庭（6+账户/投资人）
- 支持一个投资人持有多个投资组合

### 1.2 市场类型

| 市场代码 | 市场名称 | 说明 |
|----------|----------|------|
| CN_EXCHANGE | A股场内 | 在沪深交易所上市的ETF、LOF等 |
| CN_OTC | 内地场外 | 天天基金、支付宝等平台代销基金 |
| HK_MUTUAL | 香港互认 | 香港互认基金 |

### 1.3 产品类型

| 产品类型 | 说明 | 支持市场 |
|----------|------|----------|
| ETF | 交易型开放式指数基金 | CN_EXCHANGE |
| OEF | 开放式指数基金（场外） | CN_OTC |
| LOF | 上市型开放式基金 | CN_EXCHANGE/CN_OTC |
| CASH | 现金类资产 | - |

---

## 2. 核心功能

### 2.1 组合管理

- 创建投资组合，净值化管理
- 投资人份额分配与记录
- 组合净值曲线展示
- 收益统计（累计收益率、年化收益、时间加权收益率）

### 2.2 持仓管理

- 净值型资产（基金）：买入/卖出记录
- 非净值型资产（现金）：手动更新金额
- 按资产类别分组展示持仓
- 收益归因分析

### 2.3 市场数据

- 基金净值查询（Tushare/Akshare）
- 定时任务自动更新
- 数据源校验：创建产品时自动校验数据源可用性
- 历史数据同步：支持全量/增量同步

### 2.4 资产配置

- 按资产类别统计各类资产的占比（展示用）

---

## 3. 功能模块

| 模块 | 功能点 |
|------|--------|
| 投资人管理 | CRUD、角色权限 |
| 组合管理 | 创建组合、份额分配、净值曲线、收益统计 |
| 持仓管理 | 基金买卖、现金更新、收益归因 |
| 申购赎回 | 资金进出组合、份额变动 |
| 调仓交易 | 组合内部换仓、冻结金额管理 |
| 份额变动事件 | 分红、拆分、合并事件处理 |
| 市场数据 | 净值同步、数据源校验 |
| 资产配置 | 按资产类别统计占比（展示用） |
| 产品管理 | 基金产品CRUD、数据源管理 |
| 系统管理 | 交易日历、数据源配置 |

---

## 4. 权限控制

### 角色定义

| 角色 | 权限范围 |
|------|----------|
| admin | 创建组合、添加投资人、编辑交易记录、管理产品、更新市值 |
| viewer | 查看组合详情、持仓明细、收益曲线、资产配置 |

### 前端体现

- viewer 角色：隐藏"新建"、"编辑"、"删除"按钮
- admin 角色：显示完整操作入口
