## 改动 2：新增 ProductFilterSelect（筛选栏多选合并组件，#162）

新文件：`frontend/src/components/shared/ProductFilterSelect.tsx`

```ts
interface Props {
  variant?: "desktop" | "mobile";
  value: ProductSelection[];              // 受控，复用 ProductFilterDialog 的 ProductSelection
  onChange: (v: ProductSelection[]) => void; // 空数组归一由调用方处理
  className?: string;                     // 调用方传 productSelectWidth（h-9 w-[220px] / 移动 w-full）
}
```

- **容器**：outline h-9 风格（同现筛选栏按钮），内部三区：`flex-1` 文本区（可聚焦输入）+ 右侧两个图标按钮（`ChevronDown` 下拉直选、`SlidersHorizontal` 高级筛选）。
- **统一 Popover 交互**（一套实现覆盖两种入口）：
  - 点文本区或 ChevronDown → 打开 Popover：顶部搜索输入（300ms 防抖，§9）+ checkbox 列表 + footer（已选 N · 清空）；
  - 数据源：`useProductList({ page_size: 50, keyword })`（`keyword` 参数 PR159 已就绪），选项粒度 `code|market`，行显示 `name (code) · 市场`；LOF 一码多市场分行展示；
  - 勾选/取消勾选即时回传 `onChange`（变更即时查询，不设确定按钮，§9）；已选项不在当前结果集时在列表顶部固定显示（跨条件保留语义同弹窗）。
- **高级筛选按钮**：内嵌 `<ProductFilterDialog>`，以该图标按钮为触发器，`onConfirm` 直接透传 `onChange`。
- **收起态文案**：无选择显示「全部产品」placeholder（muted），有选择显示「产品 · 已选 N」。
